# 共创维护规则

这套 MATLAB 学习讲义采用共创维护方式。

## 主线文件

`chapters` 目录下的 `_完结版.mlx` 是主线讲义。学习过程中加入的公开笔记、理解、改写、纠错和补充说明，都可以成为主线内容。

后续继续完善时，优先在用户已经修改过的 `_完结版.mlx` 上继续补充，不再因为“加厚”另建新文件。

## 推送前检查

每次推送 GitHub 前，只做隐私和敏感信息检查：

1. 本机真实数据路径。
2. 私有实验数据文件名或目录名。
3. API key、token、密钥。
4. 大型私有数据文件。
5. 明确不适合公开的个人信息。

如果没有这些风险，学习笔记和讲义补充可以直接提交并推送。

## 章节版本

同一章节只保留一个公开学习版本：`_完结版.mlx`。早期多版本内容已经合并到完结版中，后续不再并行维护多个版本。

## 源脚本

`chapters_src` 中的 `.m` 文件是开发和测试辅助材料。主线内容以 `_完结版.mlx` 讲义为准；在更新源脚本或重新生成 `.mlx` 前，应避免覆盖用户已经写入主线讲义的内容。
