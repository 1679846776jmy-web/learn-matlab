# 第一阶段加厚版说明

加厚版用于补充 Ch00-Ch06 的练习密度和纠错训练。原版 `.mlx` 也可以包含学习过程中的公开笔记和改进内容，并作为后续主线讲义继续维护。

## 为什么新建 `_加厚版.mlx`

加厚版不覆盖原文件，而是生成新的 Live Script，便于把“主线讲义”和“额外训练”分开阅读：

```text
Ch00_如何使用这套讲义_加厚版.mlx
Ch01_MATLAB界面与LiveScript工作流_加厚版.mlx
Ch02_变量数组索引与基础语法_加厚版.mlx
Ch03_脚本函数路径与工程化组织_加厚版.mlx
Ch04_科研绘图基础与图形规范_加厚版.mlx
Ch05_二维三维可视化与磁面图_加厚版.mlx
Ch06_数据读写与外部数据路径配置_加厚版.mlx
```

## 加厚版新增内容

每章新增三类内容：

1. 加厚练习：更多动手改代码任务。
2. 小测验：基础选择题，帮助自查概念。
3. 错题案例：展示常见错误和正确写法。

## 推荐学习方式

1. 先复习原版 `.mlx` 中的主线讲义和学习笔记。
2. 再打开同章 `_加厚版.mlx` 完成额外练习。
3. 每遇到一个报错，把报错文字、原因和修复方法写进自己的学习日志。
