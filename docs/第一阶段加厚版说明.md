# 第一阶段加厚版说明

加厚版用于补充 Ch00-Ch06 的练习密度和纠错训练。后续维护方式已经调整为“主线 `.mlx` 共创”：学习过程中的公开笔记、理解、改写和纠错都可以直接进入原版 `.mlx`，并作为后续继续完善的基础。

## `_加厚版.mlx` 的定位

这些文件是早期补充训练包，用来集中保存更多练习、小测验和错题案例：

```text
Ch00_如何使用这套讲义_加厚版.mlx
Ch01_MATLAB界面与LiveScript工作流_加厚版.mlx
Ch02_变量数组索引与基础语法_加厚版.mlx
Ch03_脚本函数路径与工程化组织_加厚版.mlx
Ch04_科研绘图基础与图形规范_加厚版.mlx
Ch05_二维三维可视化与磁面图_加厚版.mlx
Ch06_数据读写与外部数据路径配置_加厚版.mlx
```

## 加厚版新增内容

每章新增三类内容：

1. 加厚练习：更多动手改代码任务。
2. 小测验：基础选择题，帮助自查概念。
3. 错题案例：展示常见错误和正确写法。

## 后续推荐学习方式

1. 优先学习和补充原版 `.mlx` 主线讲义。
2. 需要额外练习时，再打开同章 `_加厚版.mlx`。
3. 后续新增讲解、练习和错题案例优先合入原版 `.mlx`。
4. 每次公开推送前，只检查隐私和敏感信息。
