# 公开发布审查

本项目准备发布到公开 GitHub 仓库，因此采用以下公开边界。

## 已排除或改为本地私有的内容

1. 真实实验数据文件不进入仓库。
2. 真实 EFIT、DBS 数据所在的本机路径不进入仓库。
3. 运行讲义生成的 `.mat`、`.csv`、`.txt` 示例输出不进入仓库。
4. 本机私有路径文件 `data/external_paths/data_paths_local.m` 被 `.gitignore` 排除。

## 公开仓库保留的内容

1. MATLAB Live Script 讲义。
2. 讲义源脚本。
3. 可复现的模拟数据生成函数。
4. 基础函数库、示例脚本和测试脚本。
5. 数据路径模板 `data_paths_template.m`，其中只保留空占位符。

## 本地继续使用真实数据的方法

在本机保留：

```matlab
data/external_paths/data_paths_local.m
```

该文件会覆盖公开模板，并由 `fusionlearn.io.getExternalDataPaths` 自动优先读取。
