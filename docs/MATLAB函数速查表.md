# MATLAB 函数速查表

## 基础环境

| 函数 | 用途 |
|---|---|
| `version` | 查看 MATLAB 版本 |
| `ver` | 查看已安装工具箱 |
| `help name` | 在命令行查看简短帮助 |
| `doc name` | 打开详细文档 |
| `clear` | 清除工作区变量 |
| `clc` | 清空命令行显示 |
| `close all` | 关闭所有图窗 |
| `pwd` | 查看当前文件夹 |
| `dir` | 列出当前文件夹内容 |
| `addpath` | 添加函数搜索路径 |

## 数组和基础语法

| 函数或语法 | 用途 |
|---|---|
| `linspace` | 生成等间隔数组 |
| `zeros` | 创建全零数组 |
| `ones` | 创建全一数组 |
| `nan` | 创建 NaN 数组 |
| `size` | 查看数组尺寸 |
| `numel` | 查看元素数量 |
| `length` | 查看最长维度长度 |
| `find` | 查找满足条件的位置 |
| `mean` | 平均值 |
| `std` | 标准差 |

## 绘图

| 函数 | 用途 |
|---|---|
| `figure` | 创建图窗 |
| `plot` | 画二维曲线 |
| `scatter` | 画散点图 |
| `errorbar` | 画误差棒 |
| `histogram` | 画直方图 |
| `tiledlayout` | 创建多子图布局 |
| `nexttile` | 切换到下一个子图 |
| `xlabel` | 设置 x 轴标签 |
| `ylabel` | 设置 y 轴标签 |
| `legend` | 设置图例 |
| `grid on` | 打开网格 |
| `exportgraphics` | 导出图片 |

## 数据读写

| 函数 | 用途 |
|---|---|
| `save` | 保存 `.mat` 文件 |
| `load` | 读取 `.mat` 文件 |
| `whos -file` | 查看 MAT 文件中的变量 |
| `matfile` | 分块访问大 MAT 文件 |
| `readmatrix` | 读取数值表格 |
| `readtable` | 读取表格数据 |
| `writetable` | 写出表格数据 |
| `readlines` | 按行读取文本 |
