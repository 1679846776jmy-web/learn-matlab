# MATLAB 与聚变术语表

## MATLAB 基础

| 中文 | English | 简要说明 |
|---|---|---|
| 工作区 | workspace | 当前 MATLAB 内存中的变量集合 |
| 当前文件夹 | current folder | MATLAB 当前查找和运行文件的位置 |
| 命令行窗口 | command window | 直接输入 MATLAB 命令的地方 |
| 编辑器 | editor | 编辑 `.m` 脚本和函数的地方 |
| 实时脚本 | live script | `.mlx` 文件，可同时包含文本、公式、代码和输出 |
| 脚本 | script | 直接运行的一组命令，共享当前工作区变量 |
| 函数 | function | 有输入输出和局部变量作用域的代码单元 |
| 工具箱 | toolbox | MATLAB 的扩展功能包 |
| 路径 | path | MATLAB 查找函数和脚本的位置集合 |

## 数值计算

| 中文 | English | 简要说明 |
|---|---|---|
| 数值积分 | numerical integration | 用离散数据近似积分 |
| 数值微分 | numerical differentiation | 用离散数据近似导数 |
| 有限差分 | finite difference | 用相邻网格点近似导数 |
| 插值 | interpolation | 在已知数据点之间估计数值 |
| 线性方程组 | linear system | 形如 `A*x=b` 的矩阵方程 |
| 特征值 | eigenvalue | 描述线性系统模态性质的数 |
| 奇异值分解 | singular value decomposition, SVD | 常用于降噪、压缩和模态分析 |

## 聚变与等离子体

| 中文 | English | 简要说明 |
|---|---|---|
| 托卡马克 | tokamak | 常见磁约束聚变装置 |
| 等离子体平衡 | plasma equilibrium | 压力、电流和磁场之间的力平衡状态 |
| 磁通面 | magnetic flux surface | 磁力线绕行形成的嵌套曲面 |
| 环向磁场 | toroidal magnetic field | 沿装置环向方向的磁场 |
| 极向磁场 | poloidal magnetic field | 在截面内环绕等离子体的磁场 |
| 归一化磁通 | normalized flux | 常用 `psi_norm` 表示磁通面的归一化坐标 |
| 湍流 | turbulence | 等离子体中多尺度、不规则涨落 |
| 输运 | transport | 粒子、动量和能量跨磁面迁移 |
| 功率谱 | power spectrum | 信号能量随频率分布 |
| 相关长度 | correlation length | 涨落在空间上保持相关的尺度 |
